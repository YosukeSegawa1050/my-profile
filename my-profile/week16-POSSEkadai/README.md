# 瑞光みくじ

金色の光、朱塗りの籤筒、和紙の結果札を使ったオンラインおみくじです。筒または「おみくじを引く」ボタンを押すと、筒が揺れ、光と紙片が舞い、結果が現れます。

## 起動

```bash
pnpm install
pnpm run dev
```

`pnpm run build` で本番用ファイルを生成できます。React、Vite、Tailwind CSSのViteプラグインを使用しています。

## 機能

- 6種類の運勢からランダムに抽選
- 段階的な演出：筒を振る → 紙片が現れる → 和紙の結果札が開く
- 短歌風の言葉と、願望・恋愛・仕事・健康の助言
- 幸運の色と吉方位
- 「もう一度引く」から再抽選
- スマートフォン表示と、動きを減らす設定への対応
- キーボード操作と結果の読み上げに配慮

装飾はCSSとSVGで描いており、画像CDNに依存しません。おみくじの文章は創作で、娯楽を目的としています。
